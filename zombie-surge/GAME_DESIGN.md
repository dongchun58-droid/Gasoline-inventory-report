## 2. 게임 루프

```
[메인] 스테이지 선택(1~10, 잠금/별) → 캐릭터 선택 → [미션 시작]
  Phase A: 레인 러너  ─ 카드로 병력·화력 축적 → 문 돌파 → 미니보스 → 최종 보스
  Phase B: 필드 생존  ─ 웨이브 버티기 → 레벨업 3택1 → 진화 무기 → 보스
  Phase C: 장갑차 컨보이 ─ 도로 돌파 → 포탑/차량 업그레이드 → 거대 보스
[클리어] 별(1~3) + 코인 → 영구 업그레이드 상점 → 다음 스테이지 해금
[실패] 재도전(즉시), 또는 상점에서 강화 후 재도전
```
- 미션 하나 = **2~5분**. 광고형 게임의 "바로 시작·바로 손맛"을 유지.
- 별 조건: 클리어(★) · 병력/HP 50% 이상 유지(★) · 제한시간 내(★).

## 3. 스테이지 구성 (1→10, 난이도 상승)

### Phase A — 레인 러너 (1~4단계) "광고 속 그 게임"
| 단계 | 테마 | 새 요소 | 보스 |
|---|---|---|---|
| **1** 도시 외곽 | 낮·아스팔트 다리 | 기본 카드(`+1`~`+10`), 숫자 문(20~80), 워커 좀비 | **브루트**(거대 좀비, HP 300) |
| **2** 항만 | 노을·컨테이너 | `x2` 배수 카드, `-N` 함정 카드(피해야 함), 러너 좀비(빠름) | **스크리머**(비명으로 좀비 소환) |
| **3** 고속도로 | 밤·헤드라이트 | **무기 카드**(라이플→SMG→샷건), 폭발 드럼통, 블로터(터짐) | **탱크 좀비**(장갑, 약점 등) |
| **4** 붕괴된 시가지 | 비·번개 | **문 컨트롤**(잠긴 문: 탭 연타로 열기 vs 우회 레인), 스피터(원거리 산성), 2단 문 | **군단장**(보스+호위 20마리, 2페이즈) |

**Phase A 상세 규칙**
- 화면 세로 레인 2개(좌/우). 병력(파란 군인 무리)이 앞으로 자동 전진·자동 사격. 플레이어는 **스와이프/←→로 레인 선택**.
- 카드가 위에서 내려온다(속도 스테이지별 ↑). 통과 시 즉시 적용:
  - `+N` 병력 추가 · `xN` 병력 배수 · `-N` 병력 감소(빨강, 피할 것) · `무기↑` 전 병력 무기 교체 · `연사↑` 발사속도 · `방패` 5초 무적 · `공습` 전방 폭격.
- **문(Gate)**: 숫자 = 문 뒤 좀비 수. `병력 화력 ≥ 문 숫자` 이면 돌파, 아니면 병력이 소모되며 전투. 4단계부터 **잠긴 문**은 (a) 탭 연타로 3초 내 열기 (b) 반대 레인으로 우회 중 선택.
- 좀비 무리가 카드 사이에 배치되어 병력이 사격으로 처리. 병력 0 = 실패.
- 미니보스(중간)·최종 보스(끝) HP바 표시. 보스는 돌진/광역 공격 → 레인 이동으로 회피.

### Phase B — 오픈 필드 웨이브 생존 (5~7단계) "전후좌우 자유 이동"
| 단계 | 필드 | 새 요소 | 보스 |
|---|---|---|---|
| **5** 폐쇄 공장 | 넓은 실내, 장애물 | **자유 이동 + 오토에임**, XP 젬, 레벨업 3택1, 웨이브 타이머(3분) | **도살자**(전기톱 돌진) |
| **6** 병원 옥상 → 주차장 | 다층 | **진화 무기**(예: 샷건+연사 = 드럼 샷건, 화염병+범위 = 화염 폭풍), 배치형 **자동 포탑** 아이템 | **모체**(새끼 소환, 4분) |
| **7** 지하철 | 어둠·손전등 원뿔 시야 | **원거리 스피터 다수**, 가스 구역, 아군 생존자 구출(보너스) | **거인**(2페이즈, 5분) |

**Phase B 상세 규칙**
- 탑다운(살짝 기울인 3/4 시점). 조이스틱(터치)/WASD 이동, 가장 가까운 적 자동 조준·자동 사격.
- 좀비는 화면 밖에서 스폰되어 사방에서 조여옴 → **포위당하지 않게 계속 움직이는 것**이 핵심.
- 레벨업 3택1: 무기(피스톨/SMG/샷건/라이플/화염방사기/유탄/드론/지뢰) + 패시브(공격력/연사/이동속도/체력/자석/쿨감/범위).
- **진화 무기** 규칙: 특정 무기 Lv5 + 특정 패시브 보유 → 다음 레벨업에서 진화 제안(강력·연출).
- 보급 상자(공중 투하), 회복 팩, 폭발물, 배치형 포탑(수명 20초).

### Phase C — 장갑차 컨보이 (8~10단계) "중화기가 달린 차량"
| 단계 | 도로 | 차량 | 새 요소 | 보스 |
|---|---|---|---|---|
| **8** 국도 | 낮·3차선 | **기관총 픽업트럭** | 차량 조향(카트 게임 감각 재사용), 밀어붙이기(램), 포탑 자동사격, 바리케이드 | **좀비 트럭**(폭주 차량) |
| **9** 산악 도로 | 눈·절벽 | **장갑차(APC)** | 이중 마운트(기관총+로켓), 연료/장갑 게이지, 호위 대상(구조 버스) | **변이 거인**(도로 막음, 약점 파괴) |
| **10** 최종 방어선 | 밤·화재·요새 | **중전차형 장갑차** | 1부 컨보이 돌파(불타는 고속도로) → 2부 **가동 요새**(아래 상세) | **좀비 군주**(3페이즈, 성벽 파괴) |

**Phase C 상세 규칙**
- 좌우 조향(카트 게임 `kart.js` 주행 감각 재사용) + 자동 포탑. 램(들이받기)으로 소형 좀비 처리, 대형은 사격 필요.
- 차량 **장갑(HP)**·**연료**. 연료통/수리키트 도로에 배치. 정지하면 좀비가 달라붙어 지속 피해.
- 마운트 업그레이드는 도로 위 `무기 게이트`(카드 시스템 재사용: 기관총→미니건→로켓→화염).

**10단계 2부 — 가동 요새(Mobile Fortress) [확정]**
- 장갑차가 요새 정문에 도킹하면 **성벽 위 레일 포대**로 변신. 플레이어는 성벽을 따라 **좌우 이동**(컨보이 조향 그대로)하며 3마운트(미니건·화염·박격포)가 자동 사격.
- 화면 하단 **성벽 특수기 3버튼**(쿨다운): ① 낙문(Portcullis) — 정문 아래 좀비 압살 ② 화염 참호 — 성벽 앞 도랑에 5초 불길 ③ 포격 요청 — 탭한 지점에 3초 후 포탄 낙하(붉은 마커).
- 좀비는 성벽 3구간(좌·중·우)으로 사다리를 걸고 기어오름 → **구간별 위협 게이지**. 한 구간이 뚫리면 그 구간 성벽 HP가 깎이고, 3구간 모두 뚫리면 실패.
- 웨이브 3회(각 60초) 후 **좀비 군주** 등장: 1페이즈 정문 돌진(낙문으로 카운터) → 2페이즈 성벽 한 구간을 무너뜨려 레일이 끊김(플레이어는 남은 구간에서만 이동) → 3페이즈 군주가 성벽 위로 올라와 근접전(화염 참호·포격 콤보로 약점 노출 시 집중 사격).
- 승리 연출: 새벽, 생존자 환호, 엔드리스 모드 해금.

## 5. 플레이어·캐릭터 (실사 디테일)

### 5-1. 캐릭터 4인 (카트 게임 테마 계승 → 실사 군인 리디자인)
| 카트 게임 | 좀비 서지 | 역할/패시브 | 외형 키워드 |
|---|---|---|---|
| SMASHER(초록 근육맨) | **SMASHER — 중화기 사수** | 미니건 시작, 체력+30% | 거구, 방탄조끼, 탄띠 |
| PRINCESS(공주) | **PRINCESS — 저격/의무병** | 저격 시작, 치유 오라 | 전투복+핑크 포인트, 헤드셋 |
| COOL GUY(썬글라스) | **COOL GUY — 돌격 대장** | 라이플 시작, 이동속도+15% | 선글라스, 택티컬 재킷 |
| BIG BOSS(털보) | **BIG BOSS — 폭파 전문** | 유탄/지뢰 시작, 폭발 범위+25% | 수염, 데님·가죽, 헬멧 |

### 5-2. 실사 구현 전략 (중요 — 코딩 시 결정)
레고형을 피하기 위해 **2단계 병행**:
1. **Tier-1 프로시저럴 고디테일(기본, 무조건 동작)**: Three.js `SkinnedMesh` + 실사 인체 비율(7.5등신) + PBR(피부 SSS 근사·천 러프니스·금속 장비) + 노멀맵 텍스처(캔버스 생성, 카트 게임 `pbrtex.js` 재사용) + 본 애니메이션(idle/run/shoot/hit/die). 얼굴은 눈·코·입 지오메트리 분리, 머리카락 카드 메쉬, 장비(조끼·탄창·무전기·무릎보호대) 별도 메쉬.
2. **Tier-2 GLTF 실사 모델(권장, 품질 ↑) [출처 표기 확정]**: `GLTFLoader` + `AnimationMixer`.
   - 군인/영웅: **Adobe Mixamo** 캐릭터 + 애니메이션(무료, 게임 내 사용 허용 — Adobe 일반 이용약관). 표기: "Characters/animations: Mixamo (Adobe)".
   - 좀비/보스: **Sketchfab CC0(퍼블릭 도메인) 또는 CC-BY** 모델만 사용. CC-BY는 제작자명·URL·라이선스 표기.
   - 환경/차량 보조 자산: **Poly Haven(CC0)**, **Kenney(CC0)**, **Quaternius(CC0)**.
   - 표기 방식: ① `zombie-surge/public/assets/ASSETS.md`(파일명·제작자·URL·라이선스) ② 게임 내 **설정 › Credits** 화면에 동일 목록 자동 표시. 출처 미확인 자산은 사용 금지.
→ **코딩 순서**: Tier-1로 게임을 완성해 플레이 가능 상태 확보 → Tier-2 모델을 교체 삽입(인터페이스 동일: `buildSoldier(character)`, `buildZombie(type)` 반환 Group + `play(anim)`).

### 5-3. 병력(Phase A)·아군
- 군인 무리는 **인스턴싱**(`InstancedMesh` + 본 애니 대신 버텍스 애니/스프라이트 시트 혼합)으로 300명까지 60fps. 대장 1명만 풀 디테일.

## 6. 무기·화력 체계

| 계열 | 단계 | 진화(패시브 조합) |
|---|---|---|
| 피스톨 → SMG → 어썰트 라이플 | 1~ | 라이플+연사 = **레이저 개틀링** |

## 7. 카드·문 시스템 상세 (Phase A 핵심)

```
카드 스폰: 스테이지별 간격 (1단계 2.2s → 4단계 1.3s), 좌/우 동시 등장(선택 강제)
가중치(1단계): +N 55% / xN 10% / -N 15% / 무기 10% / 특수 10%   (단계↑ → -N·특수 ↑)
값 범위: +N (단계*3 ~ 단계*12) / xN (2~3) / -N (병력의 10~30%)
문: 숫자 = 좀비 수. 병력 DPS로 3초 내 뚫으면 '돌파', 아니면 손실. 잠긴 문(4단계~)은 탭 연타 UI
```
- **문 컨트롤 UX**: 문 30m 앞에서 화면에 "🔓 탭 연타" 또는 "↔ 우회" 버튼 표시. 연타 성공 시 병력 손실 0 + 보너스 코인.
- 카드는 **읽기 쉬운 큰 숫자**(광고와 동일한 파랑 +, 노랑 x, 빨강 -).

## 9. 진행·경제 (마을 키우기 없음)
- **런 내 성장**: 카드/레벨업 — 미션 끝나면 초기화(로그라이트).
- **영구 성장(별·코인)**: 기본 체력, 기본 공격력, 시작 병력, 카드 가중치 개선, 차량 장갑 — 5~10단계씩 소소하게. **상점 1화면**, 건물/타이머 없음.
- 해금: N단계 클리어 → N+1. 10단계 클리어 → **엔드리스 모드**(웨이브 무한, 최고 기록).

## 10. 난이도·밸런스 수식 (초기값, 코딩 후 시뮬로 튜닝)
```
좀비 HP      = base(20) × 1.35^(stage-1)
좀비 스폰수  = base(6/웨이브) × 1.25^(stage-1)
보스 HP      = 300 × 1.6^(stage-1)
카드 +N 평균 = stage × 6   (병력 성장이 좀비 성장보다 살짝 느리게 → 카드 선택이 중요)
Phase B 웨이브 길이 = 180s + 30s×(stage-5)
```
- 헤드리스 시뮬(카트 게임처럼 Playwright)로 "평균 플레이어" 봇을 돌려 클리어율 60~75%에 맞춘다.

```
zombie-surge/

  src/
    main.js        게임 상태 머신: menu → stage → (laneMode | fieldMode | convoyMode) → result

    field/         FieldSurvival(이동·스폰·XP·레벨업·진화)
    convoy/        Convoy(차량 주행 — turbo-sprint kart.js 이식·마운트·연료)
    entities/      soldier.js zombie.js boss.js vehicle.js (Tier-1 프로시저럴, Tier-2 GLTF 스왑 인터페이스)
    weapons.js     무기 정의·진화 표·투사체 풀
    hud.js input.js touch.js camera.js audio.js pbrtex.js (turbo-sprint에서 복사·수정)
```
